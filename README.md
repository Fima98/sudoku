# 🧩 Game Boy Sudoku

A simple Game Boy-styled Sudoku game.

🎮 **[Try it out](https://sudoku-sepia-two.vercel.app/)**

I built this because I wanted to play Sudoku in peace without ads, popups, or paywalls—and use it as a chance to refresh my skills with vanilla TypeScript and the DOM. I've always loved puzzle games, so building my own clean version made total sense.

### 🚀 Running Locally

```bash
# Clone the repo
git clone https://github.com/your-username/gameboy-sudoku.git

# Install dependencies
npm install

# Start dev server
npm run dev

```
