# 🧩 Game Boy Sudoku

A simple Game Boy-styled Sudoku game.

🎮 **[Try it out](https://sudoku-sepia-two.vercel.app/)**

I built this because I wanted to play Sudoku in peace without ads, popups, or paywalls—and use it as a chance to refresh my skills with vanilla TypeScript and the DOM. I've always loved puzzle games, so building my own clean version made total sense.

### ✨ Features

- **Game Boy Aesthetic:** Clean, retro-inspired monochromatic visual style.
- **Multiple Difficulties:** Choose between Easy, Medium, and Hard puzzle modes.
- **Auto-Save:** Progress automatically saves to `localStorage` so you can pause and resume anytime.
- **Validation & Notes:** Error highlighting, note-taking toggles, and cell locking.

### 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```
